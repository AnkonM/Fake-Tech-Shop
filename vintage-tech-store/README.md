# Vintage Tech Store

A polished, frontend-only vintage tech e-commerce UI demo with a retro aesthetic. Built to showcase UI/UX design and clean HTML/CSS/JS structure.

## Features
- Vintage-inspired layout with muted color palette
- Fully responsive design for desktop and mobile
- Landing page, catalogue grid, and product detail page
- Subtle hover states and tactile UI elements
- Minimal JavaScript for navigation toggle and demo alerts

## Run Locally
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Navigate between pages using the header links.

> Tip: Use a simple local server if you want consistent path behavior, but it is not required.

## GitHub Pages Deployment
1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the **main** branch and set the **/ (root)** folder.
5. Save and wait for GitHub Pages to publish the site.
6. Open the provided URL to view your live demo.

## Disclaimer
This is a frontend-only demo project. All products, prices, and interactions are fictional and for design presentation purposes only.
